# CAS Applied Data Science – Module 5: Peer Review, ML Review & Final Project Concept
<p>This repository contains materials and instructions for Module 5 of the CAS Applied Data Science program at the University of Bern.</p>

<p>Module 5 focuses on peer review, machine learning literature review, AI theory, and the development of a concept for the final CAS project. Assessment for this module is based on the peer consulting report.</p>
